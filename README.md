# みんなで運べ！

全員で1つの大きな荷物を持って、障害物のあるコースをゴールまで運ぶ協力ゲーム。スマホでリンクから参加する。2〜8人、1回およそ1〜2分。

## 遊び方

1. ホストが部屋を作り、招待URL（`/r/コード`）を送る。全員そろったらコース（5つ）と荷物（4つ）を左右の矢印で選んでスタート。ホストの選択は参加者の画面にも出る
2. 1人に1つ、荷物の持ち手がランダムに割り当てられる（前・後ろ・左・右…）。カウントダウン中に「あなたは『前』を持つ」と出る
3. 画面下のスティックで、自分の持ち手を押す向きを決める（PC は矢印キーか WASD）
4. 全員の力を足した向きに荷物が進み、持ち手の位置で回る。ばらばらに押すと回り出す
5. かけ声ボタン（せーの・右回り・左回り・止まって・ゆっくり・ナイス。PC は数字キー 1〜6）を押すと、全員の画面で自分の頭の上に吹き出しが出て音が鳴る
6. 制限時間内に、荷物の真ん中の印をゴールの枠に入れればクリア。着くと全員が跳ねて紙吹雪、結果にメダルと自己ベスト

## ルール

| | |
|---|---|
| クリア | 荷物の真ん中（白い十字の印）がゴールの枠に入る |
| 失敗: 穴 | 真ん中の印が穴の上に出ると落ちる |
| 失敗: 壊れた | 耐久が0になる。壁に速くぶつけると傷む（ゆっくり当てる分には傷まない）。外へ引っぱり合うと「引っぱりすぎ」で裂けて傷む。車・ピストンなどに当たると横へはじかれて傷む |
| 失敗: 時間切れ | コースごと（120〜170秒） |
| メダル | 到着で銅。コースの基準秒以内で銀、さらに速く耐久60以上で金。重い荷物ほど基準がゆるい（par 倍） |
| 余韻 | 到着・落下・破損・時間切れのあと 1.6 秒は演出を見せてから結果画面へ |
| スコア | クリア: 1000 + 残り秒×10 + 耐久×5。失敗: 進んだ割合×5 |
| 個人成績 | 息ぴったり率（押している間、自分の持ち手の動きと押す向きがそろっていた割合） |

荷物（4つ）:
- マットレス: 160×60。軽い（質量0.75）・丈夫（傷み0.45倍）。でも一番長い
- ソファ: 150×56。ドア（幅140）と細い通路は縦にしないと通らない
- 水槽: 110×72。重くて遅く（質量1.45倍）、ぶつけると2.2倍傷む。傷むと魚が慌てる
- ピアノ: 130×84。とにかく重い（質量1.9倍）。耐久140

コース（5つ）:
| コース | 仕掛け |
|---|---|
| 倉庫から新居まで | 狭いドア、2つの穴、ジグザグの壁、柱、細い通路 |
| 商店街の横断歩道 | 車道2本（片側1車線ずつ、車と自転車）。中央の島で待てる。看板と工事の穴 |
| 雪の坂道と橋 | 氷（よく滑る）、坂（押し戻される）、手すりの無い橋、除雪車、雪だるま |
| 工場のベルトコンベア | 穴へ流すベルト、交互に飛び出すピストン、逆向きのベルト、フォークリフト |
| マンションの階段 | 階段（重くて遅い）、吹き抜け（手すりが所々こわれている）、踊り場を歩く住人 |

全20通り（5コース×4荷物）を、2人と8人の自動操縦がゴールまで運べることを `npm test` で確かめている。

## 人数で変わるところ

- 持ち手は人数ぶん、荷物の外周に等間隔で並ぶ（2人なら前と後ろ、4人なら前・左・後ろ・右、8人なら角と辺の真ん中）
- 1人の力は「全体の力 ÷ 人数」。全員そろえば何人でも同じ速さで進み、1人だけ押すと 1/人数 の力しか出ない
- 途中で抜けた人の持ち手は止まり、残りの人数で力を分け直す。全員抜けると終わる

## 動きのしくみ

- 荷物の位置・向き・速度はサーバーだけが持つ。各プレイヤーは「押す向き（長さ1以内）」だけを送る
- サーバーは 60Hz の固定ステップで、全員の力の合力（進む）とトルク（回る）から荷物を動かす。速度と回転には減衰があり、手を離すと止まる
- 壁との当たりは、荷物の外周の点（10単位おき）と壁の角で調べ、撃力で跳ね返す。ぶつけた強さは撃力を当てる前の速さで測り、1回の衝突を二重に数えない
- 操作が 0.8 秒届かない人は手を離したとみなす（切断した人が押しっぱなしにならない）
- 画面へは 20Hz で状態を送る。画面は 110ms 遅らせて前後の状態を補間して描く（角度は近い向きに回す）
- 効果音（ぶつけた音・カウントダウン・クリア/失敗）と短い BGM は Web Audio で鳴らす。右上のボタンで消せる（端末に記憶）
- 画面に毎回送るのは荷物の位置・向き・耐久と各持ち手の押す向き、かけ声だけ（8人で700バイト未満）。コースの形は `public/stages.js` を画面側も読む
- 動く障害物の位置はスタートからの秒数だけで決まる（`moverAt`）。サーバーと画面が同じ式で計算するので、障害物の位置は送らない
- 床の仕掛けは荷物の真ん中がある所の効果がかかる: 氷=減衰0.15倍、階段=減衰+2、ベルト=ベルトの速さへ毎秒2の強さで引き寄せる
- 進んだ割合はコースの通り道（`path`）に沿って測る（折り返すコースでも正しく出る）
- BGM はコースごとに音の並びと速さを変える

## 起動

```
npm install
npm start
```

ブラウザで http://localhost:8104 を開く。ポートを変えるときは `PORT=8080 npm start`。

同じ Wi-Fi のスマホから遊ぶときは、Mac の IP で開く（例 http://192.168.0.10:8104）。

## テスト

```
npm test             # ルール・部屋・通信の単体/統合テスト（49件）
npx playwright install chromium webkit   # 初回だけ
node tools/e2e.mjs   # 実ブラウザ（chromium と webkit）で3人プレイを最後まで通す
```

`tools/e2e.mjs` は、作成→招待URLで参加→コースと荷物の選択（参加者にも見える）→開始→スティックとキーボードの操作が全員に届く→かけ声が全員に届く→自動操縦で横断歩道コースをゴールまで運ぶ→メダルと自己ベスト→再戦 を通し、各画面が 390x844 / 360x640 / 844x390 / 568x320 で上下にスクロールせず収まるかを数値で確かめる。スクショは `tools/shots/`。

`tools/autopilot.mjs` はテスト用の自動操縦（コースの `path` をたどり、動く障害物は時刻から位置を予測して手前で待つ）。ゲーム本体は使わない。
`node tools/sim-all.mjs` で全コース×全荷物×人数の結果（秒・耐久・当たった回数・メダル）を表にできる。メダルの基準秒はこれを見て決めた。
`node tools/trace.mjs <コース> <荷物>` は1回分の位置と事故を秒ごとに出す（詰まる場所を探す用）。
`node tools/shot-courses.mjs` は5コースの盤面を撮る（`W=844 H=390` で横画面）。

OGP画像は `node tools/make-og.mjs` で `public/og.png`（1200x630）を作り直せる。

## コースや荷物を足す

`public/stages.js` にデータとして書く。

- コース: `COURSES` に1つ足すとロビーの選択肢に出る。持つものは `stages.js` の冒頭に書いた（path・zones・movers・medals・theme など）。足したら `node tools/sim-all.mjs <id>` で全荷物が運べるかを見て、medals の秒数を決める
- 荷物: `CARGOS` に `{ name, lead, w, h, mass, fragile, hp, par, color }` を足すと、ロビーの選択肢に出る（描き分けは `game-view.js` の `drawCargo`）

## デプロイ

このフォルダ1つが1つのサービス。WebSocket が使えるホスティングが必要（静的ホスティング不可）。

- Render: `render.yaml`（Blueprint）。リポジトリのルートがこのフォルダでない場合は `rootDir: carry-together` を足す
- Fly.io / Cloud Run など: `Dockerfile`（ポート 8080）
- ヘルスチェック: `/healthz`
- `og:image` は届いたホスト名（`X-Forwarded-Host` / `Host`）で絶対URLに書き換えて返す

いまは手元の Mac から cloudflared のクイックトンネルで公開している（`../publish.sh`。URL は起動のたびに変わり、Mac が起きている間だけつながる）。
